# MUS205_Game
This is the final project for the course MUS 205. Our plan is to create a platformer game with a character sprite, reward sprites, enemies sprite, and an end goal sprite. 

* We may add some NPC with dialogue if possible *

The main goal of this game is to collect as much [coin] as possible, and consequently, trying to earn as much points as possible.

Step_1: 
  - Create initial class for our character. Create other sprite and move them off screen.

Step_2: 
  - Add the keyPressed().  
  - As our character move to the right, everything else moves to the left, making it seem like our canvas is a lot wider than it is.

Step_3:
  - Add audio
